# OroZendeskBundle

OroZendeskBundle adds the integration with [Zendesk](https://www.zendesk.com/) Support Ticket System to Oro applications and enables synchronization of [Oro cases](https://doc.oroinc.com/user/back-office/activities/cases/) with Zendesk tickets, and users and comments on both sides.

The bundle offers UI for admin users to enable and configure the integration, and schedule data synchronization.
